# Security Policy

## Supported Versions

Only the latest release version on the `main` branch of Sanguine Sentry is supported for security updates.

| Version | Supported |
| ------- | --------- |
| >= 0.1.0 | v Yes     |
| < 0.1.0 | x No      |

## Reporting a Vulnerability

If you discover a security vulnerability in Sanguine Sentry, please do **NOT** open a public issue. Doing so exposes the issue to the public before a fix can be prepared.

Instead, please report the vulnerability privately using GitHub's **Private Vulnerability Reporting** feature:
1. Navigate to the main page of the repository on GitHub.
2. Under the repository name, click **Security**.
3. In the left sidebar, click **Advisories**.
4. Click **Report a vulnerability** to open the draft advisory form.
5. Provide a detailed description, reproduction steps, and potential impacts.

We will review your submission and work with you to patch the vulnerability and release an update. Thank you for helping keep this project secure!
